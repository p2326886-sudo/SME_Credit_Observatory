# SME Credit Observatory
## Overview
SME Credit Observatory is a frontend analytical dashboard focused on SME
credit ecosystem monitoring and financial accessibility visualization.
The platform includes:
- credit ecosystem analytics
- lending visualization
- financial access indicators
- policy-oriented dashboard systems
- responsive analytical UI
## Features
- Modern dashboard architecture
- Responsive frontend interface
- TailwindCSS-based styling
- Multi-section layout system
- Vercel production deployment
## Tech Stack
- React
- Vite
- TailwindCSS
- GitHub
- Vercel
